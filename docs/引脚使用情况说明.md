# GD32L233R 阀门盒 引脚使用情况说明

> 适用工程：`Pressure_Regulating_Box`（App / Middle / BSP / Drivers 分层）
> 芯片：GD32L233RCT6（Cortex-M23，256KB Flash / 32KB SRAM）
> 文档基于当前代码逐行核对；标注"配置相关"的引脚由编译开关/运行标志决定，详见第 4 节。
> 最后更新：2026-08-28（对应激光甲烷/三组独立 I2C/PC3 传感器供电重构后的代码状态）

---

## 1. 工作模式概览

固件有 4 种典型运行状态，外加 4 类外设在线场景。各模式下引脚状态不同：

| 模式 | 触发 | 说明 |
|------|------|------|
| **上电初始化** | 复位后 `sys_init()` → `gpio_init()` | 关键控制脚先配成确定电平（输出），其余保持复位默认 |
| **正常运行（活跃）** | 主状态机 COLLECT / UPLOAD / DOWNLINK / ALARM / CH4 / 按键 | 按需打开外设：I2C、传感器、EEPROM、4G、CH4、LCD、BLE |
| **实时采样唤醒** | `real_set=1`，RTC 1~10s 闹钟 | 只恢复时钟 + 采集传感器 + 阈值判断，能省则省 |
| **深睡模式** | `enter_deepsleep_mode()` → `pmu_to_deepsleepmode` | 未使用引脚全部转 Analog 高阻，仅保留唤醒所需引脚 |
| **4G 在线（long 模式）** | 窗口内 / `end_result=1` | PB5 供电、PD8/9 LPUART、PA0 DTR、PA1 RI 唤醒 |
| **BLE 在线** | 三连按开启 | PC12 供电、PB3/4 UART4、PD2 连接检测 |
| **CH4 在线** | `LASER_CH4_ENABLED=1` 且 `STATE_CH4` 触发 | PC13 供电、PA2/3 USART1、预热 20s 后采集 |
| **LCD 显示** | 产品带 LCD 且已点亮 | SLCD 相关引脚 AF3，PD6 模拟输入（外部电压） |

## 3. 各模式引脚状态详解

### 3.1 上电初始化（`sys_init()` → `gpio_init()`）

`gpio_init()`（BSP/mygpio.c）先写 ODR 再切输出模式，避免电平跳变：

| 引脚 | 初始电平 | 说明 |
|------|---------|------|
| PA0 (4G_DTR) | HIGH | 允许 EC800E 休眠 |
| PB8 (BUZZER) | LOW | 蜂鸣器默认关 |
| PC3 (SENSOR_PWR) | LOW | 传感器默认断电(`SENSOR_PWR_ENABLED=1` 时配置) |
| PC12 (SW_BT) | LOW | 蓝牙默认断电 |
| PB5 (V4G_EN) | LOW | 4G 默认断电（long 模式窗口内稍后拉高） |
| PA15 (LED1) | LOW | 指示灯默认灭 |

其余引脚保持复位默认（输入浮空/模拟）。三组 I2C 总线引脚由驱动在使用前通过 `IIC_Init()` 配置：EEPROM 总线 PB6/7（`at24c64_bus_init()`）、S1 总线 PC0/1、S2 总线 PD4/5（`PT304D_CollectAll` 内部），上电阶段不预先占用。

> PC13 (CH4_PWR) 由 `ch4_power_on()` 在 `STATE_CH4` 入口显式配置为推挽输出再拉高,上电阶段不预先占用。

若 `MOTOR_ENABLED=1`，`motor_init()` 额外配置：PA5 推挽输出(使能)、PA11/PA12 输入上拉（限位）、PA6/PA7 推挽输出或 PWM（电机）。当前 `MOTOR_ENABLED=0` 跳过。

### 3.2 正常运行（活跃）

**传感器采集**（`PT304D_CollectAll`，Drivers/PT_304_35.c）：
1. `soft_i2c_init` 配置 IIC2(PC0/1, S1) 与 IIC1(PD4/5, S2) 为开漏;
2. `power_sensor_set(1)`:PC3 拉高(供电+上拉接入) → 延时 `SENSOR_PWRUP_DELAY_MS`(100ms) → 读 S1、S2;
3. `power_sensor_set(0)`:PC3 拉低(断电断上拉);采集后 `pt304d_bus_release()` 将 PD4/5、PC0/1 转 Analog。

**EEPROM 读写**（Drivers/at24c64.c / m24m01.c）：
- `at24c64_bus_init()`:配置 IIC0(PB6/7) 为开漏+死锁恢复(常供电+常上拉,与 PC3 无关);
- 读写完毕后 PB6/7 保留开漏(下次使用前重新初始化)。

**CH4 激光甲烷采集**(`STATE_CH4`,`LASER_CH4_ENABLED=1` 时):`ch4_power_on()` 显式配置 PC13 推挽输出并拉高 → `usart1_ch4_init()` 配置 PA2/3 为 AF7 → 预热 20s → 采集(2s 超时) → `ch4_power_off()` 关闭 USART1 + PC13 拉低。

**4G 上报**：PB5 拉高供电 → PD8/9 LPUART → PA0 DTR 控制模块休眠/唤醒 → 上报后按模式恢复/断电。

**阀门动作**（`MOTOR_ENABLED=1` 时）：PA5 使能、PA6/7 驱动、PA11/12 判限位；动作后拉低 PA5/PA6/PA7。当前 `MOTOR_ENABLED=0`,相关引脚全程 Analog。

**按键**：PD0 EXTI0 唤醒后检测电平（`button_is_pressed()`）。

### 3.3 实时采样唤醒（1~10s，最小化路径）

`realtime_enter_sleep()`（Projects/Wakeup_box_V0.0.1/main.c）：
- 拉低 PC3 (SENSOR_PWR,若 `SENSOR_PWR_ENABLED`);
- 4G 在线（long 模式）时：`com_lpuart_init()` + `lpuart_wakeup_init()` + `ri_exti_init()`（PD8/9 AF、PA1 EXTI 使能）；
- 按键 EXTI（PD0）、BLE EXTI（PD2，若 `g_bt_on`）按需使能；
- `enter_deepsleep_mode(lpuart_enabled)`。

每次 RTC 唤醒后 `system_wakeup_reinit()`（BSP/usart.c）只恢复时钟/SysTick/TIMER1 并关闭唤醒中断，不重配 GPIO；传感器采集时由 `PT304D_CollectAll` 内部重新配置 IIC1/IIC2 引脚并拉高 PC3。

### 3.4 深睡模式（`gpio_enter_low_power`）

深睡前除下列"保留引脚"外，全部转 Analog（高阻），以降低漏电：

| 保留引脚 | 条件 | 深睡状态 |
|---------|------|---------|
| PA0 (4G_DTR) | 恒保留 | 输出保持（DTR 电平） |
| PA1 (RI) | 4G 在线 | INPUT + EXTI1（断电时 Analog） |
| PA2/PA3 (USART1 CH4) | — | Analog(CH4 采集后 `ch4_power_off` 已 deinit) |
| PA8/PA9/PA10 (SLCD COM0-2) | LCD 亮 | AF3（LCD 关时 Analog） |
| PB0/PB1/PB9-PB15 (SLCD) | LCD 亮 | AF3（LCD 关时 Analog，并关 SLCD 时钟） |
| PB3/PB4 (BLE UART) | BLE 开 | AF8（BLE 关时 Analog） |
| PB6/PB7 (IIC0 EEPROM) | — | Analog(EEPROM 常供电+常上拉,深睡不影响) |
| PC0/PC1 (IIC2 S1) | — | Analog(采集后已转 Analog) |
| PC2 (AD_BAT) | — | Analog |
| PC3 (SENSOR_PWR) | — | Analog(深睡前 ODR 已拉低,断电断上拉) |
| PC4/PC5 (Debug 串口) | — | Analog |
| PC6-PC11 (SLCD SEG24-29) | LCD 亮 | AF3（LCD 关时 Analog） |
| PC12 (SW_BT) | 恒保留 | 输出保持 |
| PC13 (CH4_PWR) | — | Analog(CH4 采集后已拉低+deinit) |
| PC14/PC15 (LXTAL) | 恒保留 | 晶振（绝不动） |
| PD0 (按键) | `BUTTON_ENABLED=1` | INPUT + EXTI0（=0 时 Analog） |
| PD1 | `BUTTON_ENABLED=1` | 保持（=0 时 Analog） |
| PD2 (BLE_LINK) | BLE 开 | INPUT + EXTI2（BLE 关时 Analog） |
| PD4/PD5 (IIC1 S2) | — | Analog(采集后已转 Analog) |
| PD8/PD9 (LPUART) | 4G 在线 | AF8（断电时 Analog） |
| PA13/PA14 (SWD) | 恒保留 | 复位默认（不转 Analog） |

深睡由 `pmu_to_deepsleepmode()` 进入，唤醒源：RTC 闹钟 / LPUART / 按键 / RI / BLE。

### 3.5 外设在线模式

**4G 在线（long）**：PB5=HIGH、PD8/9=AF8、PA0 按 QSCLK 状态置 DTR、PA1=INPUT+EXTI1。
**4G 断电（short/dot/VLP/弱信号）**：PB5=LOW、PD8/9 转 Analog、PA1 转 Analog。

**BLE 开启**：PC12=HIGH（供电）、PB3/4=AF8（UART4）、PD2=INPUT+EXTI2（连接检测）；60s 未连接自动断电。
**BLE 关闭**：PC12=LOW、PB3/4 转 Analog、PD2 转 Analog。

**CH4 在线(`STATE_CH4`,`LASER_CH4_ENABLED=1`)**：PC13=HIGH(供电)、PA2/3=AF7(USART1),预热 20s 后采集;采集完成 `ch4_power_off()` 关闭 USART1 + PC13 拉低,PA2/3/PC13 恢复 Analog。
**CH4 离线**：PC13=LOW、PA2/3/PC13 全程 Analog(编译宏 `LASER_CH4_ENABLED=0` 时相关代码不编译)。

**LCD 开启**：PA8-10/PB0-1/PB9-15/PC6-11=AF3（SLCD）、PD6=Analog（外部电压源）。
**LCD 关闭（`LCD_LOCK_ENABLED=1` 超时）**：上述引脚转 Analog + 关闭 SLCD 时钟。
**LCD 常亮（`LCD_LOCK_ENABLED=0`）**：不关屏，每次采集自动翻页。

## 4. 编译开关与引脚

| 开关 | 位置 | 影响引脚 |
|------|------|---------|
| `EEPROM_DRV_AT24C64 / M24M01` | app_config.h | 二选一;均走 IIC0(PB6/7) 独立总线,不影响引脚 |
| `SENSOR_PWR_ENABLED` | BSP/power.h | 1=PC3 控制传感器供电+上拉(当前默认);0=传感器常供电板型,PC3 不配 |

| `LASER_CH4_ENABLED` | app_config.h | 1=启用激光甲烷(PC13 电源 + PA2/3 USART1 + STATE_CH4);0=相关代码不编译,PC13/PA2/3 全程 Analog |
| `MOTOR_ENABLED` | app_config.h | 1=启用电机(PA5/6/7/11/12);0=无电机变体,空实现,引脚全程 Analog(当前默认) |

| `BUTTON_ENABLED` | BSP/mygpio.h | 1=PD0 按键 EXTI;0=PD0/PD1 深睡转 Analog |
| `LCD_LOCK_ENABLED` | app_config.h | 1=LCD 60s 超时关屏/20s 回默认页;0=LCD 常亮+自动翻页(当前默认) |

| `APP_DEFAULT_SENSOR_COUNT` | app_config.h | 1=单传感器(只用 IIC2 PC0/1 出气端);2=双传感器(+ IIC1 PD4/5 进气端) |
| `IIC0/1/2 _SCL/_SDA _PORT/_PIN` | app_config.h | 三组独立软件 I2C 总线引脚映射(当前 IIC0=PB6/7 EEPROM,IIC1=PD4/5 S2,IIC2=PC0/1 S1) |

## 5. 注意事项

1. **三组 I2C 总线独立**:IIC0(PB6/7)=EEPROM、IIC1(PD4/5)=S2 中压/进气、IIC2(PC0/1)=S1 低压/出气,互不共享,地址无冲突风险。EEPROM 总线常供电+常上拉,传感器总线由 PC3 集中供电+上拉。
2. **PC3 (SENSOR_PWR) 是传感器供电+上拉开关**:控制 PT304D S1/S2 的电源与上拉接入,采集时拉高+延时 100ms 稳定,采集后拉低并 `pt304d_bus_release()` 将总线引脚转 Analog 杜绝漏电。EEPROM(AT24C64/M24M01)走独立 IIC0 总线,与 PC3 无关。
3. **PA2/PA3 + PC13 是激光甲烷(CH4)专用**:USART1 通信 + PC13 电源开关,由 `STATE_CH4` 入口 `ch4_power_on()` 显式配置(因从最小唤醒进入时 PC13 仍为 Analog,直接写 ODR 无效),采集后 `ch4_power_off()` 关闭。
4. **PA13/PA14（SWD）深睡不转 Analog**，保留调试能力。
5. **PC14/PC15（LXTAL）绝对不动**：RTC 与 SLCD 依赖外部晶振。
6. Bootloader 不干预任何 I2C/外设引脚(方案 B),硬件变体完全由 App 侧配置决定。
